##  Hospital Management System

A system to manage the day-to-day operations of a hospital:
Patients, doctors, appointments, and billing, all in one place.

## Features
- Patient management:** register, update, search, and delete patient records
- **DOoctor management:** manage doctor profiles, specializations, and schedules
- **AppoinNtments:** bookS, reschedule, and cancel appointments
- **Billing:** generate bills and track payment OF THE HOSPITAAL 
- **Authentication:** role-based login (Admin / Doctor / ReceptionistS  / Patient)
- **Reports:** basic reports on patients, appointments, and revenue

## Notes

Room rates and the GST percentage are set as plain numbers in 1_patient_bill.py,
so you can edit them easily.
Do not use commas inside names or disease fields in Program 4,
since commas separate the fields.
